# Sales-Trend-Analysis-Using-Aggregations


I focused on analyzing monthly sales performance using SQL Server. A CSV file containing randomly generated sales data (300 rows) was imported into SQL Server, and various SQL aggregation techniques were used to summarize and understand sales trends.

Key Highlights

Imported a custom 300-row sales dataset (CSV file).
Used SQL Server to calculate:

 -Monthly Revenue (SUM)
 -Monthly Order Volume (COUNT DISTINCT)

Performed grouping and sorting using YEAR() and MONTH() functions.
Analyzed trends in sales based on monthly performance.

Dataset Columns

 -order_id
 -order_date
 -amount
 -product_id

Technologies Used

 -Microsoft SQL Server
 -SQL Aggregate Functions
 -CSV Data Import

Output
 -A month-wise summary of total revenue and number of orders for the entire year.
